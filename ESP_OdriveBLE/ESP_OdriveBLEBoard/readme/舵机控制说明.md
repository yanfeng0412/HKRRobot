# MG90舵机控制说明

## 功能特点

1. **PWM控制**：基于ESP32-S3的LEDC外设，生成50Hz PWM信号
2. **平滑运动**：使用三次样条插值(S曲线)实现加减速过渡
3. **随机运动**：自动随机转动，模拟自然的头部运动

## 硬件连接

- **GPIO引脚**：GPIO 41
- **舵机型号**：MG90
- **角度范围**：0° - 180°
- **PWM参数**：
  - 频率：50Hz
  - 0°脉宽：500μs
  - 180°脉宽：2500μs

## API使用

### 1. 初始化舵机

```c
#include "servo_control.h"

esp_err_t ret = servo_init();
if (ret == ESP_OK) {
    printf("舵机初始化成功\n");
}
```

### 2. 设置角度（立即设置）

```c
// 设置到90度位置
servo_set_angle(90.0f);
```

### 3. 平滑移动

```c
// 平滑移动到120度，耗时2秒
servo_move_smooth(120.0f, 2000);
```

### 4. 启动随机运动

```c
// 参数说明：
// - 角度范围：30° - 150°
// - 运动时间：1000-2500ms
// - 停顿时间：500-2000ms
servo_start_random_motion(30.0f, 150.0f, 1000, 2500, 500, 2000);
```

### 5. 停止随机运动

```c
servo_stop_random_motion();
```

### 6. 获取当前角度

```c
float current = servo_get_current_angle();
printf("当前角度：%.1f°\n", current);
```

## 三次样条插值原理

使用平滑的S曲线函数：**f(t) = 3t² - 2t³**

- **起点** (t=0)：f(0)=0，速度为0（平滑启动）
- **终点** (t=1)：f(1)=1，速度为0（平滑停止）
- **中间**：加速度平滑变化，无突变

这样可以避免舵机运动时的抖动和冲击，保护机械结构。

## 当前配置

在main.c中已配置为：
- 角度范围：30° - 150°（避免机械极限）
- 运动时间：1-2.5秒（慢速运动）
- 停顿时间：0.5-2秒（模拟思考）

可以根据实际需求调整这些参数。

## 注意事项

1. 确保舵机电源充足（MG90需要4.8-6V，最大电流500-800mA）
2. 建议使用独立电源供电，避免ESP32供电不足
3. 避免长时间保持在极限角度
4. 如果舵机发热，可以增加停顿时间或减小运动范围
