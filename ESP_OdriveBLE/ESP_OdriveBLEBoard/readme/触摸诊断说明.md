# 触摸和YNF界面切换问题诊断

## 问题描述
触摸屏没有切换到YNF界面的功能。

## 诊断步骤

### 1. 已检查项目
- ✅ **引脚冲突**：舵机使用GPIO 41，触摸屏使用I2C (GPIO 8/9)，无冲突
- ✅ **任务优先级**：已将舵机任务优先级从5降低到1，避免抢占UI主任务
- ✅ **手势定义**：手势ID定义正确（UPGLIDE=0x02, DOWNGLIDE=0x01, LEFTGLIDE=0x03, RIGHTGLIDE=0x04）

### 2. 界面切换方式

**重要**：YNF界面切换不是通过普通点击，而是通过**滑动手势**触发！

- **上滑/下滑/左滑/右滑**：切换 Robot模式 ↔ YNF模式
- **点击触摸**：触发当前模式的表情切换（angry/haqi）

### 3. 调试日志

已添加以下调试信息，编译烧录后查看串口输出：

```
[触摸] 手指数: 1, 手势: 0x00, 模式: Robot
[手势检测] 检测到滑动手势: 0x02
[模式切换] Robot -> YNF
显示: YNF Idle
```

### 4. 测试步骤

1. **查看触摸是否工作**
   - 用手指点击屏幕
   - 查看串口是否输出：`[触摸] 手指数: 1, 手势: 0x00`
   - 如果没有输出，说明触摸屏本身有问题

2. **测试滑动手势**
   - 在屏幕上**快速**上下或左右滑动（不要太慢）
   - 查看串口是否输出：`[手势检测] 检测到滑动手势: 0xXX`
   - 如果没有输出，说明手势识别未生效

3. **检查手势配置**
   - 确认初始化时调用了：`CST816_Config_MotionMask(M_ALLENABLE);`
   - 这个已经在main.c中配置

### 5. 可能的问题和解决方案

#### 问题1：滑动动作不正确
**现象**：点击有响应，但滑动无效

**原因**：CST816触摸芯片需要快速、明显的滑动动作才能识别手势

**解决方案**：
- 滑动速度要快（不要慢慢移动手指）
- 滑动距离要长（至少屏幕的1/3长度）
- 手指按下后立即快速滑动，不要停顿

#### 问题2：手势识别灵敏度低
**现象**：偶尔能识别到手势，但很难触发

**解决方案**：调整CST816的手势参数（在cst816.c中）

```c
// 在CST816_Init()中添加：
CST816_IIC_WriteREG(0xEC, 0x01);  // 设置手势灵敏度（可选值1-5，1最灵敏）
```

#### 问题3：触摸屏完全无响应
**现象**：没有任何触摸日志输出

**解决方案**：
1. 检查触摸屏硬件连接
2. 检查I2C通信是否正常
3. 尝试重启设备

#### 问题4：舵机运动干扰触摸
**现象**：舵机运动时触摸失灵

**解决方案**：已降低舵机任务优先级到1，如果还有问题可以：
- 暂时停止舵机运动测试：在main.c中注释掉 `servo_start_random_motion()`
- 增加触摸检测频率：将lcd.c中的延迟从50ms改为20ms

### 6. 快速测试代码

### 7. 手势识别建议

正确的滑动操作：
1. 手指快速按下屏幕
2. 立即向一个方向快速滑动（速度要快！）
3. 手指离开屏幕

❌ **错误操作**：
- 慢慢移动手指
- 按住不动然后滑动
- 滑动距离太短

✅ **正确操作**：
- 像玩手机一样快速滑动
- 动作要流畅、果断
- 滑动距离至少5-8cm
