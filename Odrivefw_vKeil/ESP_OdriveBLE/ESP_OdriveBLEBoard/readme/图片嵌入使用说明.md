# ESP32 图片嵌入使用方法

## 方法：使用ESP-IDF的EMBED_FILES（推荐）

### 1. 准备图片
将你的JPEG图片放到 `main/images/` 文件夹中：
```
main/
  ├── images/
  │   ├── image1.jpg
  │   ├── image2.jpg
  │   └── ...
  ├── main.c
  └── CMakeLists.txt
```

### 2. 配置CMakeLists.txt（已配置）
```cmake
idf_component_register(...
    EMBED_FILES images/image1.jpg images/image2.jpg
)
```

### 3. 在代码中使用

编译时ESP-IDF会自动生成这些符号：
- `image1_jpg_start` - 文件开始地址
- `image1_jpg_end` - 文件结束地址

```c
#include "jpeg_decoder.h"

// 声明外部符号（编译时自动生成）
extern const uint8_t image1_jpg_start[] asm("_binary_image1_jpg_start");
extern const uint8_t image1_jpg_end[] asm("_binary_image1_jpg_end");

void app_main(void) {
    LCD_Init();
    
    // 计算图片大小
    uint32_t image1_size = image1_jpg_end - image1_jpg_start;
    
    // 显示图片
    LCD_ShowJPEG(0, 0, image1_jpg_start, image1_size);
}
```

### 4. 多个图片示例

```c
// 声明所有图片
extern const uint8_t image1_jpg_start[] asm("_binary_image1_jpg_start");
extern const uint8_t image1_jpg_end[] asm("_binary_image1_jpg_end");

extern const uint8_t image2_jpg_start[] asm("_binary_image2_jpg_start");
extern const uint8_t image2_jpg_end[] asm("_binary_image2_jpg_end");

void show_all_images(void) {
    // 显示图片1
    LCD_ShowJPEG(0, 0, image1_jpg_start, image1_jpg_end - image1_jpg_start);
    vTaskDelay(pdMS_TO_TICKS(2000));
    
    // 显示图片2
    LCD_ShowJPEG(0, 0, image2_jpg_start, image2_jpg_end - image2_jpg_start);
}
```

### 5. 命名规则

文件路径 | 生成的符号名称
---------|---------------
`images/photo.jpg` | `_binary_photo_jpg_start/end`
`images/my_pic.jpg` | `_binary_my_pic_jpg_start/end`
`data/logo.jpg` | `_binary_logo_jpg_start/end`

**规则：**
- 去掉路径，只保留文件名
- 将 `.` 替换为 `_`
- 前缀加 `_binary_`
- 后缀加 `_start` 或 `_end`

### 6. 添加新图片的步骤

1. 把图片复制到 `main/images/` 文件夹
2. 编辑 `main/CMakeLists.txt`，在`EMBED_FILES`后面添加新图片路径
3. 在代码中声明外部符号
4. 编译运行

### 7. 优点

✅ 无需手动转换数组  
✅ 图片直接嵌入到Flash中  
✅ 编译时自动处理  
✅ 修改图片只需替换文件，无需改代码  
✅ 支持任何二进制文件（JPEG、PNG、字体等）

### 8. 注意事项

- 图片会占用Flash空间
- 图片总大小不要超过分区大小
- 推荐图片尺寸不超过LCD分辨率（284x240）
- 使用JPEG压缩减小文件大小

### 9. 完整示例

```c
#include "lcd.h"
#include "lcd_init.h"
#include "jpeg_decoder.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

// 声明嵌入的图片
extern const uint8_t test_jpg_start[] asm("_binary_test_jpg_start");
extern const uint8_t test_jpg_end[] asm("_binary_test_jpg_end");

void app_main(void)
{
    // 初始化LCD
    LCD_Init();
    LCD_Fill(0, 0, LCD_W-1, LCD_H-1, BLACK);
    
    // 显示图片
    uint32_t jpg_size = test_jpg_end - test_jpg_start;
    printf("图片大小: %lu bytes\n", jpg_size);
    
    LCD_ShowJPEG(0, 0, test_jpg_start, jpg_size);
    
    printf("图片显示完成\n");
}
```
