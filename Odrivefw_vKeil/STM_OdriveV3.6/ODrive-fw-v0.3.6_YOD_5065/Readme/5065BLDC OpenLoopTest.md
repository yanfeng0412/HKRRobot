# BLDC Parameter

无刷电机：5065
最大功率：1800W
推荐电压：24-36V
kV值：270kV
极对数：7对14极
空载电流：0.5A~1A
空载转速： 6480~9600rpm
霍尔角度：60
扭矩：1.5~2N/m

# 命令测试合集

## 清空ERROR
$M0,E,0;

## 确认通讯
$M0,Q,0;          ← 确认通信，检查 Vbus 和 error=0

## 电流环
$M0,I,2.0;        ← 2A 小电流，验证电机有响应
$M0,H,0;          ← 急停

## 速度环
$M0,V,3.6;        ← 40 rad/s ≈ 54 rpm，等待估算器锁相
$M0,V,5;      
$M0,V,7.2;        ← 80 rad/s ≈ 110 rpm
$M0,V,18.0;       ← 200 rad/s ≈ 273 rpm
$M0,H,0;          ← 急停

# 调试bug
- 记得供电需要>8A 不然会报错或是电机带不动

Q1: 发送 $M0,V,5.0；有时候能正常转动，有时候会堵转/转得很卡，然后电流一直增大 从0.1A一直累加到1A, 情况1的空载电流只有0.1A左右而已
S1.1： 提告SPIN_UP_CURRENT 4A 换去6A 更大拖动力，转子不易脱步
S1.2：SPIN_UP_ACCELERATION 80rad/s^2 换去 50rad/s^2 更慢，转子有时间跟上
S1.3： SPIN_UP_TARGET_VEL 150rad/s 换去 250rad/s 切换闭环时反电势从0.44V升到0.73V，观测器锁定更可靠
