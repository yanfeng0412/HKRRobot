🐛 关键 Bug 根因分析
BUG-A：motor_dir = -1 导致剧烈振动噪声
根因：motor_dir 同时影响 FOC 相位角和速度反馈符号
hall_phase_from_pos() 中： phase = (2π/6) × (pll_pos − phase_offset) × motor_dir
phase_offset = 3.5f 是在 motor_dir = 1 时校准的。
改成 -1 后，相位公式整体取反但 offset 不变 → FOC 磁场与实际转子偏差约 120°~180°
→ sin(相位误差) ≠ 1 → 产生横向力矩分量 → 振动 + 噪声 + 效率急剧下降。
观察到的现象
M0 motor_dir=-1：剧烈抖动，噪声极大，Iq 纹波 ±5A
M1 motor_dir=+1：安静，Iq 纹波 <1A
→ 两台电机硬件完全相同，差异来自 motor_dir 配置
正确修复：应用层方向宏，FOC 参数不动
APP_M0_VEL_DIRECTION = -1，在 V 命令处理中 vel_rad_s *= app_dir[motor_idx]
motor_dir 恢复为 1，phase_offset 保持 3.5f，FOC 校准完整性不受影响。
⚠ 结论：motor_dir 是 FOC 校准参数，改动它需要重新校准 phase_offset。
任何方向反转需求应在指令层通过方向乘数（APP_Mx_VEL_DIRECTION）实现，不要修改 motor_dir。
BUG-B：同帧多命令 M1 丢失
根因：';' 仅作为 parse_buffer 内容，不触发解析
DMA 缓冲区收到 $M0,V,5.0;$M1,V,5.0;（共 22 字节），
解析器逐字节入 parse_buffer，遇到 '\0' 或 '\r' 才触发 motor_parse_cmd。
';' 被写进 parse_buffer，sscanf 解析 "$M0,V,5.0;$M1,V,5.0" 时仅提取 M0 参数，
M1 部分在 sscanf 消耗完后丢弃。
修复：';' = 帧内命令分隔符（不 break while）
遇 ';' → null 终止 parse_buffer → 调用 motor_parse_cmd → 重置 idx 和 read_active
但不 break → 继续消耗 DMA 后续字节 → 解析 $M1 命令
BUG-C：M1 Hall-C GPIO PB3 = JTAG SWO 冲突
根因：PB3 复用为 SYS_JTDO-SWO
J-Link 通过 SWO 输出 printf 时，PB3 电压被拉低，Hall_C 读到 0。
正常 Hall 编码序列中 bit2（Hall_C）读 0 导致 Hall state = 原值 & ~4，可能产生无效 state=7。
修复：Hall-C 改接 PC15（M1_DC_CAL 焊盘）
PC15 为 GPIO 输入，无复用冲突，解焊 M1_DC_CAL 焊盘并飞线到 Hall-C。
⚠ PC15 与 PC9（M0 Hall-C）共享 EXTI15_10 中断线，但两处均使用 GPIO 轮询，不依赖 EXTI，无冲突。

重要经验总结
motor_dir 是 FOC 校准参数，不是方向开关
motor_dir 影响 hall_phase_from_pos()（定子磁场角）和 get_pll_vel()（速度符号），两者必须保持一致。
改变 motor_dir 必须同时重新校准 phase_offset，否则相位偏差 → 振动/飞车。
方向控制请用 APP_Mx_VEL_DIRECTION。
CMSIS-RTOS v1 无 osSignalClear，用 osSignalWait(signal, 0) 代替
timeout=0 非阻塞消耗信号位，是 drain 积压信号的唯一正规方法。
Hall CPR=6 的速度量化噪声放大机制
每机械圈 6 次 Hall 边沿 ≈ 18ms/次 (at 5km/h)。
每次边沿 pll_vel 产生一次冲击脉冲（幅值 ∝ pll_ki × δpos）。
高积分增益将此冲击积分到 Iq → 可闻噪声。降低 vel_integrator_gain 可有效抑制。
GPIO 引脚复用冲突必须在调试前排查
PB3 = SWO，PB4 = JTMS 等 JTAG 引脚不应用于信号输入。查阅 STM32F405 引脚表确认无复用冲突。
主动制动 vs 惯性滑行
保持 FOC 运行、设 vel_setpoint=0 产生主动制动力矩，制动效果比直接关 PWM 好 3~5 倍；halt_timeout 防止停止后 FOC 空跑耗电。
⚠ 方向配置提醒：如需修改 M0 或 M1 的运动方向，只修改 APP_M0_VEL_DIRECTION / APP_M1_VEL_DIRECTION（值为 1 或 -1），切勿修改 APP_HALL_MOTOR_DIR。
✅ 下次上电流程：上电 → 等待校准完成（心跳 calib=1）→ 直接发 $M0,V,5.0;$M1,V,5.0; → 双电机同步启动，无需 $M0,E,0
